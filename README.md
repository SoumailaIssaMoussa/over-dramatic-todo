# over-dramatic-todo

Projets MERN: backend et frontend.

Notes:
- Créez un fichier `.env` local à partir de `.env.example` et remplissez vos valeurs privées.
- **Ne commitez jamais** le fichier `.env` contenant vos secrets.

Instructions rapides:
```bash
# backend
cd backend
npm install
npm start

# frontend
cd frontend
npm install
npm run dev
```
